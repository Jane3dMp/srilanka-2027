# Шри-Ланка 23.02–09.03.2027

Личный travel-гид по маршруту на двоих. Одна статическая страница: чистый HTML + CSS + JS
в `index.html`, без сборщиков и зависимостей. Внешние ресурсы — только Google Fonts,
встроенная карта Google Maps и фотографии с Wikimedia Commons.

- 4 базы: Элла → Хапутале → Нувара-Элия → Тангалле
- 29 точек с координатами, ссылками на карту и фотографиями
- Схема маршрута — inline-SVG по координатам, связана со списком в обе стороны
- Светлая и тёмная тема, мобильный приоритет

Фотографии остаются на серверах Wikimedia Commons; автор и лицензия указаны
под каждым снимком.
